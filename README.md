# Эмулятор UNIX-подобной оболочки — вариант 22

## Общее описание

Проект реализует вариант №22 практической работы по дисциплине
«Конфигурационное управление». Эмулятор выполнен на Python и работает
через графический интерфейс Tkinter.

Основные возможности:

- GUI с заголовком `Эмулятор - [username@hostname]`;
- простой разбор команд по пробелам;
- команды `ls`, `cd`, `du`, `uniq`, `mkdir`, `touch`, `vfs-load`, `exit`;
- виртуальная файловая система в оперативной памяти;
- загрузка VFS из JSON;
- двоичные данные VFS хранятся в base64;
- стартовые скрипты с комментариями и отображением ввода и вывода;
- тестовые скрипты для разных вариантов VFS.

Физические файлы VFS не изменяются командами `mkdir` и `touch`.
Изменения выполняются только в объекте VFS в памяти.

## Запуск

Требуется Python 3.10 или новее и Tkinter.

Запуск основного приложения:

```bash
./run.sh --vfs vfs/sample.json
```

Запуск со стартовым скриптом:

```bash
./run.sh --vfs vfs/files.json --script stages/stage4.script
```

Запуск тестов:

```bash
PYTHONPATH=. python3 -m unittest discover -s tests -v
```

## Параметры командной строки

`--vfs PATH` — физический путь к JSON-файлу виртуальной файловой системы.

`--script PATH` — физический путь к стартовому скрипту.

Оба параметра могут использоваться одновременно.

## Формат VFS

Корень JSON является каталогом:

```json
{
  "type": "dir",
  "children": []
}
```

Каталог содержит `children`. Файл имеет тип `file` и поле `data` с
содержимым в base64.

## Команды

### `ls [опции] [путь]`

Показывает содержимое каталога.

Поддерживаются режимы:

- `ls` — обычный список;
- `ls -a` — добавляет `.` и `..`;
- `ls -l` — показывает тип и размер;
- `ls -a -l` — объединяет режимы.

### `cd [путь]`

Переходит в каталог. Поддерживаются абсолютные и относительные пути,
а также `.` и `..`.

### `du [путь]`

Показывает рекурсивный размер объекта в байтах.

### `uniq путь`

Удаляет последовательные одинаковые строки из UTF-8 файла VFS.

### `mkdir путь`

Создаёт каталог только в памяти.

### `touch путь`

Создаёт пустой файл только в памяти.

### `vfs-load путь`

Загружает другой JSON-файл VFS с физического диска в память и переводит
текущий каталог в `/`.

### `exit`

Завершает работу эмулятора.

## Стартовые скрипты

Стартовый скрипт является обычным текстовым файлом. Пустые строки и строки,
начинающиеся после пробелов с `#`, считаются комментариями.

При выполнении каждая команда отображается как ввод пользователя, после неё
выводится результат команды.

## Скрипты реальной ОС

В папке `scripts` находятся shell-скрипты для проверки параметров запуска и
разных вариантов VFS:

- `stage1.sh` — запуск GUI;
- `stage2.sh` — VFS + стартовый скрипт;
- `stage3_minimal.sh` — минимальная VFS;
- `stage3_files.sh` — VFS с несколькими файлами и каталогом;
- `stage3_deep.sh` — VFS с тремя и более уровнями;
- `stage4.sh` — основные команды;
- `stage5.sh` — дополнительные команды и `vfs-load`.

## Ограничения реализации

Эмулятор не распаковывает JSON-VFS на диск. Команды изменения состояния
работают с деревом объектов в памяти. Команда `vfs-load` читает новый JSON
файл и заменяет текущую VFS в памяти.
